## References

### Textbooks
* **[Yanofsky2008]** Noson S. Yanofsky and Mirco A. Mannucci. *Quantum Computing for Computer Scientists*. Cambridge University Press, 2008.

### Software & SDKs
* **Qiskit SDK:** An open-source SDK for working with quantum computers at the level of circuits, pulses, and algorithms.
  * [GitHub Repository](https://github.com/Qiskit/qiskit)
* **NVIDIA cuQuantum:** A SDK of optimized libraries and tools for accelerating quantum computing workflows.
  * [NVIDIA Developer Portal](https://developer.nvidia.com/cuquantum-sdk)
